NoTraitPyro

Adds a context-menu option to light paper-like items on fire. Uses flexible flammability rules and includes Build 42 timed-action compatibility.

Status: Released.
Core idea: Make the \"set fire\" interaction feel like it belongs, without hard-coding a tiny item list.
