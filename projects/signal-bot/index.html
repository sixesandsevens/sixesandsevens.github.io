signal-bot

A small Signal bot built around signal-cli JSON-RPC: subscribers, keyword replies, rate limiting, and a PIN-gated admin mode for updating help responses.

Status: Running.
Focus: predictable behavior in group chats, with guardrails.
Core features: subscription list, simple keyword replies, rate limiting, and admin-only commands.
Technical overview:
signal-bot wraps signal-cli’s JSON-RPC interface as a small message-processing service: incoming messages are parsed into commands/events, then routed through handlers with rate limits and basic auth gates. The design goal is “boring reliability” on a small host.
  • Transport: JSON-RPC calls to signal-cli for send/receive, group metadata, and attachment handling.
  • Routing: command parsing + keyword matching with explicit handler ordering to avoid ambiguous triggers.
  • Guardrails: per-sender cooldowns, opt-in subscriptions, and a PIN-gated admin mode for editing help/response text.
  • Ops: structured logging and safe defaults so failures degrade gracefully instead of spamming chats.
