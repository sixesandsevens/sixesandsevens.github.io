What It Does

Import pages (photos/images/PDF), reorder them, pad to a foldable 8-page batch, preview the print-order spreads, and export an imposed PDF you can print and fold.

Screenshots

Technical overview

ChickenPress is a Flutter app built around a deterministic “imposition planner”: it takes an arbitrary pile of pages (photos/scans/PDF pages), normalizes them into a consistent page model, then generates foldable 8-page signatures and exports a print-ready PDF.

  • Import pipeline: decode images, rasterize PDF pages when needed, and keep a lightweight preview cache so the reorder UI stays fast.
  • Imposition logic: compute page ordering and sheet-side placement for each 8-page batch; pad with blanks to reach valid fold counts.
  • Preview: render “spread” previews that match export placement (rotation, margins) so the plan matches the print.
  • Export: write an imposed PDF with predictable sizing so viewers and printers don’t “helpfully” rescale the output.

Why I Made It

Because zines often start as a pile of imperfect pages, and the last mile (imposition and a printable plan) should not require a full design suite or a ritual.

Roadmap

Export polish, better presets, persistence for settings/projects, and a smoother scan/import flow.
