Zine Imposer

A CLI (plus optional preview UI) that turns PDFs or images into print-ready booklet/zine imposition. Pads page counts and exports imposed spreads for folding and stapling.

Status: Released.
Format: CLI-first, “give me a printable file” focused.
Downloads: planned for the release shelf.
Technical overview:
Zine Imposer is an imposition engine wrapped in a CLI: it ingests PDFs or image sets, computes booklet signatures, and emits a new PDF where each output sheet contains the correct page pairings for folding. The optional preview UI is a thin layer over the same planner so what you see is what you export.
  • Input normalization: coerce mixed sources into a consistent page model (size, rotation, crop).
  • Signature planning: pad to valid booklet sizes and compute front/back page ordering per sheet.
  • Output generation: write a print-ready PDF with stable dimensions (no surprise scaling) and optional spacing.
  • Repeatability: deterministic planning so reruns produce the same layout for the same inputs.
