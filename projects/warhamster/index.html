Warhamster.app

A lightweight virtual tabletop for quick battlemaps: sketch rooms, drop assets, move tokens, and keep everyone in sync in real time.

Status: Active (online-ish).
Highlights: Rooms + auth, realtime WebSocket sync, tokens, freehand + shapes, asset library, snapshots, undo/redo.

Screenshots

Technical overview

Warhamster is a browser-first realtime app: each “room” is a shared document (board state + token state + asset references) with a small event protocol for syncing edits. The goal is low-latency collaboration without forcing heavyweight accounts or complex setup.

  • Realtime sync: a WebSocket channel per room broadcasts discrete board events (draw, move, add/remove, change properties) so clients apply updates incrementally.
  • State model: room state is kept normalized (layers/objects/tokens/assets) so snapshots and undo/redo can be implemented as small patches.
  • Assets: imported images are treated as references with metadata (size/transform) and reused across boards via an asset library.
  • Snapshots: “save points” are stored as serialized room state for fast rehydration and sharing specific moments in play.
