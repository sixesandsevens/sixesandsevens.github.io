PZ Modsmith

A local helper for generating clean Project Zomboid server mod lines from console logs or Workshop IDs. Scans local downloads, handles multi-mod items, and produces reviewable reports.

Status: Released.
Format: CLI-first.
Use case: turn messy mod lists into something you can paste into a server config without summoning new errors.
Technical overview:
PZ Modsmith is a local, CLI-first parser + resolver: it ingests messy inputs (server console logs, Workshop IDs, partial names), resolves them into a normalized mod set, and emits output you can verify before you paste it into a config. The workflow is intentionally “review, then apply” to reduce downtime on multiplayer servers.
  • Input parsing: extract Workshop IDs and mod IDs from logs and freeform text, handling duplicates and mixed formats.
  • Local resolution: scan downloaded Workshop content to map IDs → actual mod folder IDs (including multi-mod workshop items).
  • Output generation: produce server-ready lines and a human-readable report listing what was found, what was missing, and what looks suspicious.
  • Safety: keeps destructive actions out of band; the tool emits recommendations rather than silently modifying game installs.
