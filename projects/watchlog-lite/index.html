WatchLog-Lite

A lightweight WatchGuard log viewer (Flask): fast tailing, filters/highlighting, export, and a few quick “top talkers” summaries.

Status: Active / in use.
Stack: Python + Flask.
Focus: speed and readability — make the log stream feel like a tool, not a punishment.
Technical overview:
WatchLog-Lite is a lightweight Flask app that tails one or more log files, parses lines into structured records, and provides a fast in-browser filter/view layer. It’s built for triage speed: get to the relevant handful of entries, export them, and move on.
  • Tailing: incremental follow that avoids reprocessing whole files and keeps UI updates cheap.
  • Parsing: normalize timestamps, src/dst, service, and message fields so filters can be consistent.
  • Filtering/highlighting: query + pattern rules plus color tags for “known bad” strings.
  • Summaries: small aggregation queries (top talkers, common denies, bursty sources) for quick situational awareness.
