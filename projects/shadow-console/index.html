Shadow Console

Polls the UniFi Integration API, stores snapshots in SQLite, and generates small “diff” events (uplink moves, offline devices, roam flapping) with a tiny Flask dashboard.

Status: Internal / in use.
Stack: Python + Flask + SQLite.
What it’s for: turning “something changed” into a short, reviewable event list instead of a vibe.
Technical overview:
Shadow Console runs a scheduled poller against the UniFi Integration API, normalizes device/site state into stable tables, and computes diffs between snapshots to emit “small events”. The dashboard is intentionally minimal: it’s optimized for answering “what changed, when, and does it matter?”.
  • Snapshotting: store periodic device + uplink + status fields in SQLite with timestamps for cheap historical comparisons.
  • Diff events: detect deltas like uplink port changes, offline/online transitions, and excessive roam flapping.
  • Filtering: collapse noisy repeats into a single event stream you can scan quickly.
  • Dashboard: a simple Flask UI for browsing recent events and drilling into the underlying snapshot data.
