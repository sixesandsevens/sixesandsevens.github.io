GuestDesk

A kiosk-friendly Flask + SQLite web app for publishing a service directory and schedule, posting announcements, and collecting guest submissions with reference numbers.

Status: Deployed / in use.
Core pieces: services + schedule, announcements, submissions, light staff/admin flows.
Screenshots: coming soon (home screen + admin landing are the money shots).
Technical overview:
GuestDesk is a small Flask app designed for “public screen + private admin” deployments: guest-facing pages are kiosk-friendly, while admin workflows are optimized for rapid edits during live events. Data lives in SQLite so deployments stay simple and portable.
  • Public pages: service directory, schedule, announcements, and “what’s happening now” views designed for large displays.
  • Submission flow: a minimal form that issues reference numbers so staff can triage and follow up without exposing personal info on-screen.
  • Admin mode: protected routes for editing entries, scheduling, moderating submissions, and exporting quick reports.
  • Deployment: runs behind a reverse proxy (or locally on a small box) with a single DB file for backup/restore.
