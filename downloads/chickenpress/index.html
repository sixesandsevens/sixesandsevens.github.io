Linux: run it

Download the .tar.gz, extract it, then run the executable inside the extracted folder.

Download: chicken-press-linux-x64.tar.gz 

cd ~/Downloads
tar -xzf chicken-press-linux-x64.tar.gz
ls

# cd into the extracted folder (name may vary)
cd chicken-press-linux-x64*

# run the app (pick the executable you see in this folder)
ls
./chicken-press

If Linux blocks it as “not executable”, run chmod +x ./chicken-press and try again.
