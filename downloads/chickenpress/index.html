Notes

This is an early alpha build of Chicken Press. It can format images/PDFs into printable zine layouts and export print-ready files.

Windows users may see a SmartScreen warning because the installer is not code-signed yet.

Windows:

Use the installer (recommended) or the portable zip. 

# Installer (recommended)
1) Download chicken-press-windows-x64-setup.exe
2) Run it and follow the prompts
3) Launch Chicken Press from the Start Menu

# Portable
1) Download chicken-press-windows-x64.zip
2) Extract it
3) Run the Chicken Press .exe inside the extracted folder

Linux:

Download the .tar.gz, extract it, then run the executable inside the extracted folder. 

cd ~/Downloads
tar -xzf chicken-press-linux-x64.tar.gz
ls

# cd into the extracted folder (name may vary)
cd chicken-press-linux-x64*

# run the app (pick the executable you see in this folder)
ls
./chicken-press

If Linux blocks it as “not executable”, run chmod +x ./chicken-press and try again.
